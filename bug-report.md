# Bug Report: Login Form

*Учебный пример баг-репорта. Описанный дефект смоделирован и не подтверждён фактическим тестированием реального приложения.*

## BUG-001. HTTP 500 при отправке формы авторизации с пустыми полями

**Тип дефекта (Issue Type):** Bug

**Серьёзность (Severity):** Major — предварительная оценка

**Приоритет (Priority):** High — предварительная оценка

**Статус (Status):** Open — условный статус учебного примера

**Окружение (Environment):** Google Chrome, Windows 11 (условное окружение)

### Предусловия (Preconditions)

- Открыта страница авторизации веб-приложения.
- Поля Email и Password доступны для ввода.

### Шаги воспроизведения (Steps to Reproduce)

1. Открыть страницу авторизации.
2. Оставить поле Email пустым.
3. Оставить поле Password пустым.
4. Нажать кнопку Log in.
5. Дождаться ответа приложения.

### Ожидаемый результат (Expected Result)

- Авторизация не выполняется.
- Пользователь получает сообщение о необходимости заполнить обязательные поля.
- Приложение корректно обрабатывает запрос без возникновения серверной ошибки.

### Фактический результат (Actual Result)

*Предполагаемый результат учебного сценария:*

После нажатия кнопки страница перестаёт отвечать на несколько секунд, затем отображается ошибка HTTP 500 Internal Server Error.

### Примечание

Дефект смоделирован для демонстрации структуры баг-репорта. Фактическое воспроизведение ошибки на реальном приложении не проводилось.

Для подтверждения подобного дефекта при реальном тестировании необходимо проверить ответ сервера и сетевые запросы, например во вкладке Network в Chrome DevTools.
