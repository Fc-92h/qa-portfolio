# Примеры тест-кейсов (Test Cases)

В этом разделе представлены примеры тест-кейсов для проверки формы авторизации веб-приложения. Они демонстрируют навыки составления тестовой документации, проверки позитивных и негативных сценариев.

## TC-001. Успешная авторизация с корректными данными

**Предусловия:**
- Пользователь зарегистрирован в системе.
- Открыта страница авторизации.

**Шаги:**
1. Ввести зарегистрированный email в поле Email.
2. Ввести корректный пароль в поле Password.
3. Нажать кнопку Log in.

**Ожидаемый результат:**
Авторизация проходит успешно. Пользователь перенаправляется на главную страницу профиля.

## TC-002. Авторизация с неверным паролем

**Предусловия:**
- Пользователь зарегистрирован в системе.
- Открыта страница авторизации.

**Шаги:**
1. Ввести зарегистрированный email в поле Email.
2. Ввести неверный пароль в поле Password.
3. Нажать кнопку Log in.

**Ожидаемый результат:**
Авторизация не выполняется. Пользователь остаётся на странице входа и видит сообщение об ошибке, предусмотренное требованиями приложения.
