# Интеграция Discord и Telegram

**Тип проекта:** личный технический проект

### Описание проекта

Разработка и настройка интеграции между Discord и Telegram для автоматической передачи сообщений с распределением по соответствующим разделам и темам.

Самостоятельно определила требования к функциональности, разработала логику взаимодействия между платформами и настроила ботов в Discord и Telegram. Для реализации программной части использовала AI-ассистента, участвовала в доработке кода и проверяла корректность работы реализованных функций.

Настроила Discord-приложение через Discord Developer Portal, организовала размещение и запуск бота на Bot-Hosting.net.

### Инструменты и технологии

- **Python** — реализация программной логики с использованием AI-ассистента.
- **Discord Developer Portal** — создание и настройка Discord-бота.
- **Telegram Bot API** — интеграция с Telegram.
- **Bot-Hosting.net** — размещение и запуск приложения.
- **Discord, Telegram** — взаимодействие между платформами.

### Основные задачи и личный вклад

- Определение требований и проектирование логики взаимодействия между платформами.
- Создание и настройка ботов в Discord и Telegram.
- Настройка передачи сообщений и их распределения по соответствующим разделам.
- Ручная проверка функциональности и выявление ошибок.
- Анализ обнаруженных проблем, доработка реализации с помощью AI-ассистента и повторная проверка исправлений.
