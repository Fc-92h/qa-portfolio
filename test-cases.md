# Примеры тест-кейсов (Test Cases)

Ниже представлены примеры тест-кейсов для проверки формы авторизации (Login) в веб-приложении.

## 1. Успешный вход в систему с правильными данными

* **Предусловие:** Пользователь уже зарегистрирован в системе, страница входа открыта.
* **Шаги:**
  1. Ввести существующий Email в поле «Email».
  2. Ввести правильный пароль в поле «Password».
  3. Нажать кнопку «Log in».
* **Ожидаемый результат:** Пользователь успешно авторизован, открывается главная страница профиля.

## 2. Попытка входа с неверным паролем

* **Предусловие:** Страница входа открыта.
* **Шаги:**
  1. Ввести существующий Email.
  2. Ввести случайный или неверный пароль.
  3. Нажать кнопку «Log in».
* **Ожидаемый результат:** Вход не выполнен, под формой появилось сообщение об ошибке: «Неверный логин или пароль».
