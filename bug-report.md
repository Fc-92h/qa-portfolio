# Пример баг-репорта (Bug Report)

## ID дефекта: BUG-001
* **Заголовок:** Ошибка 500 при попытке авторизации с пустыми полями
* **Серьезность (Severity):** Major (Значительная)
* **Приоритет (Priority):** High (Высокий)
* **Статус:** Open (Открыт)
* **Окружение:** Google Chrome (версия 122.0), Windows 11

---

### Шаги воспроизведения (Steps to Reproduce):
1. Открыть страницу авторизации веб-приложения: `https://example.com/login`.
2. Оставить поля «Email» и «Password» пустыми.
3. Нажать кнопку «Log in».

---

### Ожидаемый результат (Expected Result):
Под полями ввода появляется валидационная ошибка о том, что поля обязательны для заполнения. Переход на главную страницу не происходит.

---

### Фактический результат (Actual Result):
Страница зависает на 2–3 секунды, после чего отображается стандартная системная страница с ошибкой сервера «HTTP 500 Internal Server Error».
