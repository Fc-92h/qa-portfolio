# Пример баг-репорта (Bug Report)

*Учебный пример. Дефект смоделирован для демонстрации навыков оформления баг-репортов.*

## BUG-001. Ошибка HTTP 500 при отправке формы авторизации с пустыми полями

**Серьёзность (Severity):** Major — предварительная оценка  
**Приоритет (Priority):** High — предварительная оценка  
**Статус (Status):** Open  
**Окружение (Environment):** Google Chrome, Windows 11 (условное окружение)

### Шаги воспроизведения (Steps to Reproduce)

1. Открыть страницу авторизации веб-приложения.
2. Оставить поля Email и Password пустыми.
3. Нажать кнопку Log in.

### Ожидаемый результат (Expected Result)

Авторизация не выполняется. Пользователь получает сообщение о необходимости заполнить обязательные поля. Запрос не приводит к серверной ошибке.

### Фактический результат (Actual Result)

После нажатия кнопки страница перестаёт отвечать на несколько секунд, затем отображается ошибка HTTP 500 Internal Server Error.
