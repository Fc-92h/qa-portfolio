# Примеры тест-кейсов (Test Cases)

Ниже представлены примеры тест-кейсов для проверки функционала **Авторизации (Login)** веб-приложения.

## 1. Успешный вход в систему с валидными данными
* **Предусловие:** Пользователь зарегистрирован в системе, страница авторизации открыта.
* **Шаги:**
  1. Ввести валидный Email в поле «Email».
  2. Ввести валидный пароль в поле «Password».
  3. Нажать кнопку «Log in».
* **Ожидаемый результат:** Пользователь успешно авторизован, открывается главная страница профиля.

---

## 2. Попытка входа с неверным паролем
* **Предусловие:** Страница авторизации открыта.
* **Шаги:**
  1. Ввести валидный Email.
  2. Ввести неверный/случайный пароль.
  3. Нажать кнопку «Log in».
* **Ожидаемый результат:** Авторизация не выполнена, под формой появляется сообщение об ошибке: «Неверный логин или пароль».
