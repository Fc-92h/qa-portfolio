# Test Cases: Login Form

## Описание

Учебные тест-кейсы для проверки формы авторизации веб-приложения.

**Объект тестирования:** форма авторизации.

**Область тестирования:** проверка ввода учетных данных и поведения приложения при попытке входа.

**Типы тестирования:** функциональное, позитивное и негативное.

**Примечание:** ожидаемые результаты приведены для типового поведения формы авторизации. При тестировании реального приложения их необходимо сверять с требованиями.

---

## TC-001. Успешная авторизация с корректными данными

**Приоритет:** High

**Тип:** Positive

**Предусловия:**
- Пользователь зарегистрирован в системе.
- Известны корректные email и пароль пользователя.
- Открыта страница авторизации.

**Тестовые данные:**
- Email: зарегистрированный email пользователя.
- Password: корректный пароль.

**Шаги:**
1. Ввести зарегистрированный email в поле Email.
2. Ввести корректный пароль в поле Password.
3. Нажать кнопку Log in.

**Ожидаемый результат:**
- Авторизация проходит успешно.
- Пользователь перенаправляется на страницу профиля или другую страницу, предусмотренную требованиями.
- Пользователю доступны функции, требующие авторизации.

**Тип:** Negative

- Авторизация не выполняется.

## TC-006. Проверка отображения пароля

**Приоритет:** Medium

**Тип:** Functional / UI

**Предусловия:**
- Открыта страница авторизации.

**Шаги:**
1. Ввести пароль в поле Password.
2. Проверить, как отображаются введённые символы.
3. Если предусмотрена кнопка показа пароля, нажать её.
4. Повторно нажать кнопку показа пароля, если она позволяет переключать режимы.

**Ожидаемый результат:**
- По умолчанию пароль скрыт, если такое поведение предусмотрено дизайном.
- При использовании кнопки показа пароль отображается открытым текстом.
- При повторном переключении пароль снова скрывается.

---

## Примечания

- Тест-кейсы составлены для учебной практики.
- Ожидаемые результаты необходимо уточнять по требованиям конкретного приложения.
- Результаты выполнения тестов не указаны, поскольку фактический прогон на конкретном приложении не проводился.
